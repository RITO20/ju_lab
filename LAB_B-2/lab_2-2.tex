    \(\textit{\textbf{Write Python code to implement a Logistic Regression Model for Spam detection}}\)

    Logistic regression is often mentioned in connection to classification
tasks. The model is simple and one of the easy starters to learn about
generating probabilities, classifying samples, and understanding
gradient descent

    Logistic regression as mentioned above is mostly used for classification
tasks thats why the output of this is in most cases is 1/0, yes/no etc
or in form of probalility of 1.

    In linear regration the main equation us y = mx + c.~

and here the main equation is =\textgreater{}
\(\sigma(z) = \frac{1}{1+e^-z} = h\)

    where \(z = wx + b\)

    From the above the Liklyhood fuction is
\(l = \prod_{i = 1}^{m}[h^y][1-h]^{1-y}\)

    Loss Liklyhood Function =\textgreater{}
\(L = ln(l) = \sum_{i=1}^{m} yln(h) + (1-y)ln(1-h)\)

    nagative average loss likelyhood fucntion =\textgreater{}
\(J = -\frac{1}{m} L\)

    Now for gradiant decent we need 2 functions 1.
\(\frac{\delta J}{\delta w} = \frac{\delta J}{\delta h} \times \frac{\delta h}{\delta z} \times \frac{\delta z}{\delta w} \\\\ \hspace{0.5cm}= \sum_{i=1}^{m} [[\frac{y}{h} - \frac{1-y}{1-h}] \times [h (1-h)] \times x] \\\\ \hspace{0.5cm}= \sum_{i=1}^{m}(y-h)x\)

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\setcounter{enumi}{1}
\tightlist
\item
  \(\frac{\delta J}{\delta b} = \frac{\delta J}{\delta h} \times \frac{\delta h}{\delta z} \times \frac{\delta z}{\delta b} \\\\ \hspace{0.5cm}= \sum_{i=1}^{m} [[\frac{y}{h} - \frac{1-y}{1-h}] \times [h (1-h)]] \\\\ \hspace{0.5cm}= \sum_{i=1}^{m}(y-h)\)
\end{enumerate}
